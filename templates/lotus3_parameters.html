sdm options files

Each LotuS3 run picks one "sdm options" file (in lotus2_files/) that controls read quality filtering, primer matching and demultiplexing before clustering/denoising happens. The file is chosen automatically from the upload's Sequencing_platform, unless an admin explicitly overrides it from the dropdown on the project page (Step 12).
